Important database design decision:

We should implement a many-to-many relationship between Users and Roles.

For example:
- One application can have 4–5 administrators.
- Multiple users can have the Developer role.
- One user can have multiple roles.
- Permissions should be managed independently from user accounts.
This provides flexibility instead of hardcoding roles directly into users.
